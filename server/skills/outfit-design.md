# 新品造型

用户要买衣服或看新品时使用。从衣橱搭一套时不使用本技能。有风格技能时，轮廓、配色和能不能加外套以风格技能为准，本技能只补共同的造型判断。

## 先定主角
- 一套只有一个主角。主角是用户点名的那一类；没点名时，是这套里量感最大或颜色最深的一件。
- 其余单品为它服务：颜色更安静，轮廓更简单，不和主角抢领口、袖型和装饰。
- 用户点名外套时，外套就是主角，内搭和下装收着。
- 用户点名的是一整套品类（汉服、连衣裙、套装）时，这套自己就是主角。不要再叠斗篷、大衣、棉服、羽绒服。保暖写在该品类自己的面料和里衬上。

## 配色
- 先定明度，再定色相。整套里要有一块压住的深色，或一组明确对比。禁止每件都是相近的浅色。
- 一套里重复一个元素即可：同一色相、同一金属，或同一圆角。不要领、袖、裙摆、鞋、包各自装饰一遍。
- 肤色只用来决定主角偏暖还是偏冷。没有肤色分析时，不要编造肤色理由。

## 轮廓
- 一套只做一种对比：松对紧，或长对短。不要上装、外套、裙子同时宽松。
- 腰线、肩线、下摆至少有一处是清楚的。三层都盖住腰时，这套没有结构。
- 长度要能读出来：短到哪、长到哪写进外观。不要用「适中」「刚刚好」。

## 两套方案
- 两套必须是两种结构。可以是裤和裙、短外套和长外套、上紧下松和上松下紧。
- 禁止同一件短上衣配长下装，只换一个颜色再出一套。
- 两套的主角不要是同一品类加同一配色公式。

## 检索
- 有天气穿衣细则时，厚度跟细则，本技能不改温度档。
- 用户点名买冬季外套时，外套 query 用厚外套、大衣、棉服、羽绒服。
- 有风格技能时，品类按风格技能，不要改成厚外套。
