# 穿搭相容法则

件与件能否待在同一套。只写互验与禁止态，禁止具体套装配方或款名清单。
有 style-* 时仍适用：风格管「长什么样」，本技能管「能不能待一起」。

## 气质同族
- 一套只走一条气质主轴（如淑女、日常休闲、运动训练、职场、街头）。
- 气质冲突的单品禁止硬凑进同一套。

## 氛围对齐
- 鞋、包、配饰与服装必须同属一条风格–氛围线。
- 看衣橱 XML 的 formality、tags、occasions、description：训练档不当日常出门主搭；街头机能包不配淑女上装；商务结构包不配纯休闲套。
- 不用「正式度分数」叙事；用氛围是否同一条线判断。

## 面料族相容
- 按面料说话方式归族（精致梭织、针织柔软、硬质结构、运动机能），信号优先 description，其次 material 与 tags。
- 同族可通过；有意一对硬×软对比可通过。
- 禁止无理由跨族，尤其精致梭织与运动机能同框。

## 厚薄同叙事
- 同套单品厚薄叙事须一致；档位与是否加腿层认天气穿衣技能。
- 禁止薄裙面与厚外套各说各话却当合理成套。

## 内外包容
- 外套或套头外层的量感须容纳内搭。
- 贴身套头禁止罩在鼓囊、宽松内搭外。

## 场合拉开
- 约会、通勤、纯日常对鞋包下装的氛围下限不同；禁止三场合同一配方敷衍。
- 用户场合词落在 occasions/formality 上时，按该场合选件，不把训练服扩成日常。

## reason 写相容
- 选用理由至少点气质、氛围或面料之一。
- 禁止只写配色、明度或温度。

## 边界
- 厚薄档与层数认 weather-dressing。
- 配饰开槽、数量、金属统一：无 style 时认 accessory-pairing；有 style 时认风格鞋包节。
- 本技能不展开具体鞋型或包款清单。
