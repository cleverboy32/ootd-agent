# 小个子

身高约 160cm 及以下，或用户说小个子、显高时使用。这是长短配比的硬性限制。不规定具体品类路线。

## 比例
- 一套里只保留一个主要长度：上装短、下装长，形成清晰的高低差。不要短外套、中长外层、中长下装各自都是中等长度，三段接在一起会把人切碎。
- 腰线做高，高于自然腰。用高腰头或把上装下摆收进腰头，把腿的起点抬上去。
- 外套停在腰或髋以上，或者长到膝以下但保持瘦长的一条线。禁止外套下摆停在大腿中部，那是把腿截断的位置。
- 下装止点停在脚踝骨，或刚好盖住鞋面一点。下摆堆在鞋上、或停在小腿肚，都会压矮。
- 若下装露出小腿：要么在膝上留出小腿，要么到脚踝且腰是高的。不要停在小腿最粗的中间。

## 体积
- 每件衣服的松量只松一档。肩、袖、下装开口不要同时夸张。
- 大包、厚底超过一掌、过长的围巾会占掉身高。鞋可以有一点厚度，但鞋头要短，不要又长又厚。
- 图案用小的，或整件一个颜色。大格子会把一块面积量得更短。

## 不要
- 过膝又不到脚踝的大衣，再配同长度的中长下装。
- 低腰、宽腰带、多层荷叶边、泡泡袖加大摆同时出现。

## 检索
- 有天气细则时，厚度跟细则。
- query 用高腰、九分或踝上止点、短外套或瘦长外套。不要搜低腰、堆在鞋上的下摆、及大腿中部的外套。
