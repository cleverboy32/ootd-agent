## 重新生成源码页

源码有较大变更后，在仓库根目录执行：

```bash
node scripts/export-soft-copyright-source.mjs
```

脚本会按 Gatekeeper → Intent → RAG → Stylist → Copywriter → Visual → … 顺序拼接，每页 50 行，输出前/后各 30 页，并脱敏疑似密钥行。

## 导出 PDF（提交前必做）

版权中心一般要求上传 PDF。任选一种方式：

### 文档鉴别材料 = 软件说明书

版权中心说的「程序设计说明书 / 用户手册」等，我们用的就是 `02-软件说明书`（功能、安装、架构、使用方法都在里面）。

- 全文约 **14 页（< 60）→ 提交整个 PDF**，不用拆前 30 / 后 30  
- 文件：`design/soft-copyright/02-软件说明书.pdf`  
- 重生：`node scripts/export-soft-copyright-manual.mjs`

### 源程序鉴别材料

- 文件：`03-源码鉴别材料/源码鉴别材料-合并.pdf`（约 60 页 = 前 30 + 后 30）  
- 重生：`node scripts/export-soft-copyright-source.mjs`  
- `.txt` 分页符 Pages 常不认，Mac 直接用 PDF 即可。

## 网上提交 SOP（本周执行）

登记入口：中国版权保护中心 — [https://www.ccopyright.com.cn/](https://www.ccopyright.com.cn/)（以官网当时入口为准，常见为「计算机软件著作权登记」网上办理）。

```text
准备材料 → 注册个人账号并实名
        → 新建「计算机软件著作权登记」申请
        → 按 01-登记信息稿 逐项填写
        → 上传：源码 PDF、说明书 PDF、身份证正反面
        → 确认并提交 → 在线缴费
        → 下载/保存「受理通知书」（比赛可先用）
        → 等待审查 / 补正 → 下证（约 1～2 个月，以当期为准）
```
