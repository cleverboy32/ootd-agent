# 文艺

文艺是一件柔软、质地看得见的衣服，配安静的其余部分。不是森系配饰堆满身。

## 主角
- 主角要能看出柔软或纹理：针织、棉麻、绒、有褶的长裙。其余单品比它更简单、更贴。
- 轮廓偏松一档，但要有一个长度停住：袖口、裙长或裤脚。不要每一件都拖到地。
- 不要潮牌的夸张肩和超大裤脚，也不要古装的交领广袖。

## 配色
- 颜色沉静：棕、橄榄、灰蓝、米色、深蓝，选一个做主色。可以有一小块暖色，放在内搭或围巾。
- 禁止荧光，禁止整套浅粉，禁止高饱和撞色。
- 纹样如果有，是小的、旧的、密度低的，只在一件上。

## 层次
- 最多两层。内层在领口露出来即可。不要斗篷加压马甲再加压短外套。
- 围巾或衬衫的领可以代替一件配饰。有了领部的层次，就不要再加项链。

## 鞋与配饰
- 鞋用平底、短靴或简洁皮鞋，颜色接近下装或更深。不要厚底运动鞋，不要绣花鞋。
- 配饰一件：书本感的小包、细眼镜，或一条围巾。不要发簪、珍珠多层和大手袋一起。

## 两套方案
- 两套主角的材质不同。一套针织或棉麻上衣，一套长裙或绒面。
- 不要两套都是长开衫配长裙。

## 检索
- 有天气穿衣细则时，厚度跟细则。
- 没有天气细则时，query 用针织、棉麻衬衫、长裙或直筒裤、平底鞋。不要搜卫衣、汉服、厚底鞋、亮面缎裙。
