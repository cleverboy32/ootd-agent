# 冷调肤色

档案或用户原话是冷调、冷皮时使用。只约束颜色，不改剪裁。不要因为用户说冷、加外套，就套用本技能。

## 贴着脸
- 领口、围巾、耳饰用冷色：冷白、灰色、蓝色、冷粉、黑色。
- 白色可以用冷白。黑色可以贴脸。
- 驼色、杏色、橘色、芥末黄不要放在领口。它们可以做裤子或包。

## 金属与深浅
- 金属用银，或无金属。不要金饰贴着脸。
- 一套里仍要有明度差。不要全身冷灰浅粉，没有一块深色。

## 检索
- query 不写蓝色、灰色这类具体色。用户点名颜色时才用浅色、深色、冷色。
- 有天气细则时，厚度跟细则。
