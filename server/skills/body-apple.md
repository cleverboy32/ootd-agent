# 苹果形

档案或用户原话出现苹果形时使用。这是剪裁限制，风格技能不能把它改掉。

## 体积放哪
- 腰腹不收紧、不系死、不堆褶。腰部留出直线或很浅的弧，不要用宽腰带勒出腰。
- 体积放在肩线和腿的垂直线上。肩部适中的结构能把视线拉开，V 领、长开领或有纵向线条的门襟把中段拉长。
- 不要在胃的位置加口袋、荷叶边、短款蓬松下摆或横条。

## 腰线与长短
- 上衣和外套的下摆不要停在腰腹最满的地方。短则停在胸下到高腰之间，长则过臀，中间这段不要切一刀。
- 下装用高腰，但腰头是平的、不勒。裤和裙从腰向下是直的或轻微离开身体，不要在小腹处堆褶。
- 裙长过膝更稳。膝上裙只有在腰腹已经被平顺的上衣盖住时才用。
- 外套敞开或半敞，露出一条垂直的内搭。不要把短款圆摆外套系在最满的那一圈上。

## 不要
- 紧身收腰、宽腰带、empire 腰下接一圈大裙摆、肚脐处的短 T 恤。
- 上身横条、下身又在胯部加宽。全身紧身。

## 检索
- 有天气细则时，厚度跟细则。
- query 用直筒、高腰、V 领或纵向门襟、过臀的上衣。不要搜宽腰带、收腰短外套、包身。
