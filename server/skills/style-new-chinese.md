# 新中式风格定义 (Modern Neo-Chinese Style)

新中式的核心是“现代利落剪裁 + 一处精巧的中式细节”，追求含蓄克制、古今交融的东方高级感。
绝对禁止：汉服戏服感堆叠（如马面裙配大衣、广袖/披帛）、全身多处中式元素并发（如立领+盘扣+斜襟+满身刺绣同时出现）、整套大面积满身刺绣/高饱和大印花。

## 1. 核心结构与单一要素原则 (Structure & Single Element Limit)
- **单一中式要素硬限**：全套搭配必须且**仅能保留 1 处**明确的中式细节（如：立领、盘扣、斜襟、或侧边隐蔽微开衩），其余部分完全按照现代服装剪裁。
  - **规则示例**：若上衣使用了盘扣门襟，则领口必须简洁，下装绝不能再带盘扣或中式刺绣。
- **现代骨架剪裁**：肩线、腰线、裤腿完全遵循现代干练结构（如挺括西装肩、高腰直筒裤、一步裙/利落 A 字裙）。
- **外套与轮廓禁区**：外套仅限无帽短款或及髋现代挺括外套。**绝对禁止**连帽外套、拖地长斗篷、广袖大衣与马面裙叠穿。

## 2. 配色与图案 (Color & Pattern)
- **水墨沉静基调**：主色必须由沉稳的东方色调压阵（如：墨黑、深藏青、烟灰色、冷棕色、靛蓝）。
- **点缀色与浅色控制**：允许使用低饱和辅色（如竹青、香膏白、月白）做内搭或领口露出。**绝对禁止**整套浅驼/杏色/米白毛绒堆叠在一起。
- **图案与刺绣克制**：图案仅限低调暗纹或小面积刺绣，刺绣面积**严格小于衣身的 10%**。禁止满身大面积彩绘或高饱和大花卉印花。

## 3. 面料与重感碰撞 (Fabric & Texture Weight)
- **外层重感压阵**：外层或主角单品须选用有结构克重的面料（如：重磅羊毛、挺括香云纱、醋酸重磅缎、重磅棉麻、粗针织）。
- **内轻外重搭配**：内层可选用轻盈真丝或棉麻，但**绝对禁止内外层同时起绒**或大面积使用廉价薄纱。
- **面料禁区**：禁止高光亮面尼龙、廉价化纤化缎、大面积防晒网纱。

## 4. 鞋履与配饰 (Shoes & Accessories)
- **现代干练鞋履**：
  - **女性**：平底/粗跟乐福鞋、方头平底皮鞋、简洁尖头短靴、利落板鞋。
  - **男性**：极简皮质乐福鞋、方头/圆头德比鞋、黑色哑光切尔西短靴、极简板鞋。
  - **通用禁区**：绝对禁止中式绣花鞋、汉服布履、厚底老爹鞋、粗犷雪地靴、拖鞋。
- **配饰极简**：全套配饰控制在 **1 件以内**。
  - **女性**：小巧玉石耳钉、细金属锁骨链、冷感银饰。
  - **男性**：冷感银质戒指/小耳钉、精致皮质腕表、竹节/极简定型皮质包。
  - **通用禁区**：绝对禁止发冠、步摇、多层璎珞项链。
- **包袋规范**：结构极简的现代定型皮质包或竹节手提包，绝不破坏现代线条。

## 5. 多方案推荐规范 (Multi-Option Rules)
当需要提供 2 套方案时，必须满足：
- **下装与中式要素位置异构**：
  - **女性**：一套必须为【裤装方案（如高腰直筒西裤/阔腿裤）】，另一套必须为【裙装方案（如一步裙/利落直筒半裙）】。
  - **男性**：一套必须为【盘扣/斜襟上装 + 高腰直筒西裤（上装细节）】，另一套必须为【立领针织/衬衫 + 挺括阔腿裤/直筒裤（领口细节）】。
  - **通用要求**：中式细节位置必须打散（如一套细节在领口，一套细节在门襟盘扣）。
- **拒绝同质化**：绝对禁止两套方案均为“盘扣短外套 + 黑色裤/裙”的敷衍同质化设计。

## 6. 检索生成逻辑 (Search Query Guidelines)
- **Query 拼接**：所有槽位的 Query 必须包含`新中式` + 性别词 (`男` / `女`) + 明确现代品类与结构（如`新中式女 立领盘扣短外套`、`新中式男 高腰直筒西裤`，而不是单纯的`汉服`或`盘扣`）。
- **通用天气适应逻辑**：
  - **有天气细则时**：厚薄听从天气要求（寒冷天气自动检索毛呢盘扣外套、加厚直筒裤），但新中式规则锁定“单一中式要素与沉静配色”。屏蔽马面裙、连帽斗篷、汉服广袖、运动街头装。
  - **无天气细则时**：默认检索基础四季新中式单品（新中式立领衬衫、高腰直筒裤、一步裙、无帽盘扣短外套、平底皮鞋）。
