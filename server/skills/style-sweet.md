# 甜美/少女与元气风格定义 (Sweet & Youthful Style)

甜美风的核心是“柔和色调”、“精致设计细节”与“灵动元气感”，追求清新自然、减龄且层次协调的东方少女/元气感。
绝对禁止：无主次堆叠甜美元素（如泡泡袖+蕾丝+大蝴蝶结+褶皱同时出现）、全身高饱和荧光色、影楼/童装感夸张蓬蓬裙、廉价起毛薄纱、厚底雪地靴/运动拖鞋。

## 1. 核心比例与单一甜度主角 (Silhouette & Focal Point)
- **单一甜度要素硬限**：全套搭配必须且**仅能有 1-2 处**明确的甜美设计细节（如：娃娃领、泡泡袖、小蝴蝶结、荷叶边、微褶皱或印花选一），其余单品必须保持线条干净剪裁。
  - **路径 A（上甜下简/裤装）**：甜美元素设计款上衣（如娃娃领衬衫/泡泡袖针织） + 线条简洁的高腰直筒裤/九分牛仔裤。
  - **路径 B（连体/裙装）**：甜美连衣裙或高腰 A 字/百褶半裙 + 线条利落的开衫/短外套。
- **轮廓与松紧**：保持灵动与轻盈度。上装可轻微蓬松，但腰线或下装线条须保持清爽（禁止全身上下均呈臃肿蓬松球状）。

## 2. 色彩与甜度调控 (Color & Sweetness Control)
- **柔和配色体系**：主色选用柔和、清新或中性浅色（奶油白、燕麦色、蜜桃粉、浅水蓝、薄荷绿、奶油黄）。
- **深色/中性色压阵**：必须搭配一件中性色或深色单品压制甜腻感（如：牛仔蓝、烟灰色、燕麦棕、炭黑收口）。
- **甜酷特别分支 (Sweet Cool)**：
  - **女性**：“甜”占 30%-50%（如蕾丝/碎花上衣），“酷/硬”占 50%-70%（如高腰牛仔裤、短款皮衣、马丁靴）。
  - **男性（日系元气少年感）**：以马卡龙/奶油色系软质针织或浅色衬衫为主，搭配宽松奇诺裤/直筒裤，展现干净减龄感。
- **色彩禁区**：绝对禁止全身高饱和荧光色、全身超过 3 种对比强烈的颜色混搭。

## 3. 面料与质感 (Fabric & Texture)
- **推荐面料**：亲肤柔软的精纺针织、重磅纯棉、垂坠雪纺、柔软牛仔、小面积蕾丝/刺绣。
- **面料硬度对比**：鼓励用挺括面料（牛仔、挺括西装面料、皮革）与柔软甜美面料做刚柔碰撞。
- **面料禁区**：绝对禁止廉价反光化纤、易起球劣质面料、大面积透光粗糙网纱。

## 4. 鞋履与配饰 (Shoes & Accessories)
- **鞋履推荐**：
  - **女性**：法式玛丽珍鞋、芭蕾舞平底鞋、干净小白鞋/德训鞋、小巧乐福鞋、简洁短靴。
  - **男性**：干净极简小白鞋/德训鞋、浅色帆布鞋、皮质乐福鞋。
  - **通用禁区**：绝对禁止粗犷厚底老爹鞋、拖鞋、超高跟细带凉鞋、厚底雪地靴。
- **配饰减法**：全套配饰控制在 **1-2 件以内**。
  - **女性**：精致珍珠耳钉、发带/小丝带、极细锁骨链。
  - **男性**：极简帆布包、浅色棒球帽、简约手表。
  - **通用禁区**：禁止夸张金属粗链条、汉服发冠/步摇、影楼夸张发饰。

## 5. 多方案推荐规范 (Multi-Option Rules)
当需要提供 2 套方案时，必须满足：
- **下装与结构异构**：
  - **女性**：一套必须为【裤装甜美方案（如甜美上衣+高腰直筒裤）】，另一套必须为【裙装方案（如百褶半裙/连衣裙+薄开衫）】。
  - **男性**：一套必须为【浅色马卡龙针织衫/Polo+直筒裤】，另一套必须为【叠穿衬衫+卡其奇诺裤/短裤】。
- **拒绝同质化**：绝对禁止两套方案仅更换颜色（如粉色针织换成杏色针织）或仅更换鞋包的敷衍设计。

## 6. 检索生成逻辑 (Search Query Guidelines)
- **Query 拼接**：所有槽位的 Query 必须包含`甜美`或`少女` + 性别词 (`男` / `女`) + 明确细节/轮廓（如`甜美女 娃娃领衬衫`、`元气男 奶油色针织衫`，而不是单纯的`衬衫`）。
- **通用天气适应逻辑**：
  - **有天气细则时**：厚薄听从天气要求（寒冷天气自动检索加厚甜美开衫、羊毛短外套、加厚牛仔裤），但甜美规则锁定柔和配色与单一甜度细节。屏蔽连帽工装外套、汉服、大面积破洞街头装。
  - **无天气细则时**：默认检索基础四季甜美单品（甜美针织开衫、娃娃领衬衫、高腰半裙/直筒裤、玛丽珍鞋/小白鞋）。
