# 梨形

档案或用户原话出现梨形时使用。这是剪裁限制，风格技能不能把它改掉。不规定具体品类路线。

## 体积放哪
- 增加体积的位置只在肩、领和胸以上。肩线可以略平、略宽，用有形状的袖或适中垫肩，让肩和胯看起来接近。
- 胯、臀、大腿外侧禁止再加体积：不要袋盖、不要侧边荷叶边、不要紧绷的横缝、不要亮面和厚实的侧缝装饰。
- 上装用有一点量的面料，下装用垂坠、不贴肉的面料。不要上下都贴身，也不要上下都蓬。

## 腰线与长短
- 腰线做高。腰头停在自然腰或以上，把最宽的胯分到下装里。
- 上衣停在腰线附近，或刚好盖住腰头。禁止上衣的下摆停在胯最宽的地方。
- 下装从腰向下垂，胯部留松量，到大腿中部以后可以收直。禁止贴臀，禁止在膝下突然横向放大。
- 外套长度要么停在腰以上，要么长到大腿中部以下。禁止外套下摆正好切在臀围最大处。

## 不要
- 低腰、胯部紧身、胯部鼓起的灯笼廓形、下装开口正好卡在腿最宽处。
- 上身又紧又短、下身又紧又亮。细肩带如果没有外层，会把肩缩得更窄，不要单独当主角。

## 检索
- 有天气细则时，厚度跟细则。
- query 用高腰、垂坠或直筒轮廓、有肩线的上衣。不要搜低腰、贴臀、紧身短下装。
