## 五、项目差异化策略（BP / PPT 写作要点）

1. **可演示的 Demo** — 评委对 AI 项目最在意"能不能跑"，线上体验地址 + 录屏双保险
2. **技术壁垒 = 工程化能力**：
   - 多 Agent 编排架构（Gatekeeper / RAG / Stylist / Copywriter / VisualDirector）
   - Prompt 回归测试体系（`tests/prompts/`，真实 LLM 断言）
   - 全链路可观测性（`log/*-audit.jsonl`：意图分布、检索命中率、效果图质量审核）
3. **商业化路径**（需先想清楚讲哪个）：
   - C 端订阅：AI 穿搭助手 App
   - B 端 SaaS：服装品牌 / 电商的穿搭推荐 API
   - 衣橱数字化服务
4. **就业带动叙事** — 人社局主办赛事看重"创业带动就业"：落地金牛意愿 + 3 年用人计划 + 预期营收
5. **区域契合** — 支持单位含 AI 数字创智元 OPC 社区，主动表达落户意向是隐性加分

## 七、线上合规整改（ICP 备案 + 生成式 AI 登记）

> 现状：产品已部署 `www.meetu.online/ootd`，但 ① 域名 ICP 备案信息与本产品不符（按其他用途备案）；② 模型对话功能未对外开放。当前只是展示页，合规暴露面小；**对外开放对话前必须完成 7.2**。

### 7.1 ICP 备案变更（第 1 周提交，整体约 1~3 周）

目标：备案的网站名称/服务内容与实际上线产品一致，消除抽查被注销备案、封域名的风险。

- [ ] 确认 `meetu.online` 解析到的服务器接入商（阿里云 / 腾讯云等），登录对应备案控制台，查清当前备案的网站名称、服务内容、主体信息（个人还是企业）
- [ ] 提交「变更备案」（变更网站信息）：网站名称改为 OOTD-Agent / AI 穿搭助手，网站内容简介与服务内容类别对齐「数字产品服务」
- [ ] 接入商初审（约 1~2 工作日，会电话核实）→ 工信部短信核验（收到后 24h 内完成）→ 省通信管理局审核（约 5~20 工作日）
- [ ] 变更审核期间网站**可正常访问**（不同于首次/新增备案，无需关站）
- [ ] 通过后 30 日内完成**公安联网备案**（全国互联网安全管理服务平台 `beian.mps.gov.cn`，纯线上提交，约 1 周）
- [ ] ⚠️ 注意主体限制：若当前备案主体为**个人**，只能做非经营性内容；比赛展示页问题不大，但后续商业化（收费订阅）前须注册公司并做主体变更或新增企业备案

### 7.2 生成式 AI 服务登记（开放对话的前置条件，周期约 1~3 个月）

前提：面向公众提供服务必须调用**已完成大模型备案的境内模型**。代码 OpenAI 兼容路径已支持 DeepSeek / Kimi / 豆包（火山引擎），均已备案（`server/config/models.ts`）；Vertex/Gemini 路径仅限内部开发，不可用于对公众服务。

- [ ] 确认生产环境 `LLM_VENDOR` / `IMAGE_VENDOR` 指向境内已备案模型（DeepSeek + doubao-seedream），不要用 Vertex 上生产
- [ ] 联系属地网信办（四川省 / 成都市网信办）确认「生成式人工智能服务登记」流程与材料清单（各省模板略有差异，先问再备）
- [ ] 准备登记材料：
  - 服务基本信息（产品形态、功能描述、用户规模预估）
  - 调用模型的已备案证明（模型名称、提供方、备案编号——DeepSeek / 豆包官网可查）
  - 安全评估报告（自评估：语料与知识来源、内容安全过滤机制、拒答策略）
  - 内容安全管理制度 + 投诉举报入口
  - AI 生成内容标识方案：效果图显式标注「AI 生成」角标 + 图片元数据隐式标识（符合《人工智能生成合成内容标识办法》，2025-09-01 起施行）
- [ ] 提交登记并跟进补正
- [ ] 同步评估**深度合成算法备案**（互联网信息服务算法备案系统 `beian.cac.gov.cn`；AI 效果图生成属深度合成范畴）

### 7.3 过渡期演示策略（比赛期间）
