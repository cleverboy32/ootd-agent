# 天气穿衣细则

按「三明治」管**大类层次与厚薄**：内层上装 →（需要时）中/外层外套。  
**不管**裙还是裤、开衫还是风衣款式、什么颜色——那些交给风格技能与场合。

## 使用步骤
1. 从【今日穿搭意图】的天气文本中读取温度、天气现象、风力、湿度；读不到的项跳过
2. 按温度落入唯一一个档位（边界值按表中区间归属，如 25℃ 属「舒适」，26℃ 属「偏热」）
3. 叠加命中的修正项；风力 ≥6 级时温度档位下调一档
4. 用户点名某层次（如不要外套、只要短袖）时，按用户要求，优先于本表
5. 用户说冷、外套不够暖：外套只升相邻一档。微凉升到凉 → 中厚；凉升到冷 → 厚。禁止从薄档直接跳到羽绒服、厚大衣
6. 据此决定要不要外套槽、上装袖长/厚度、外套厚薄。reason 用实际温度和体感说明，不得出现「档」「档位」「修正项」「细则」或表中的档位名称

## 温度档位（层次与厚薄）

- **薄外套**：飞行员夹克、连帽拉链衫、牛仔外套、西装外套、薄风衣、薄开衫
- **中厚外套**：摇粒绒、薄棉服、稍厚针织外套、防风软壳、夹棉薄外套（有填充但不臃肿）
- **厚外套**：大衣、棉服（明显蓬松）、羽绒服、派克

| 档位 | 温度 | 大类层次 | 上装厚度 | 外套厚度 |
|---|---|---|---|---|
| 炎热 | ≥ 28℃ | 上装 + 下装；不检索外套 | 短袖、无袖 | 无 |
| 偏热 | 26–27℃ | 上装 + 下装；室内空调可加一件薄外套 | 短袖 | 可选薄 |
| 舒适 | 22–25℃ | 上装 + 下装 + 建议薄外套 | 短袖或薄长袖 | 薄 |
| 微凉 | 18–21℃ | 三明治：上装 + 薄外套 + 下装 | 长袖或薄针织 | 薄 |
| 凉 | 13–17℃ | 三明治：上装 + 中厚外套 + 下装 | 长袖或针织等保暖上装 | 中厚 |
| 冷 | 8–12℃ | 三明治：保暖上装 + 厚外套 + 下装 | 毛衣、针织 | 厚（大衣、棉服） |
| 寒冷 | ≤ 7℃ | 三明治：保暖内搭上装 + 厚外套 + 下装 | 毛衣、保暖内搭 | 厚（羽绒服、厚大衣） |

下装：只保证有下装大类；**裙或裤由风格决定**。炎热/偏热可短装下装；微凉及以下靠上装+外套保暖，不要求必须是长裤。

## 检索 query
- 天气只约束：是否检索 `outerwear`、上装厚薄用词、外套厚薄用词。
- 外套：薄档用开衫、薄风衣、衬衫外套等；中厚档用摇粒绒、薄棉服、软壳、稍厚针织外套；厚外套（大衣、蓬松棉服、羽绒服）只在冷、寒冷两档。
- 薄档外套 query 禁止羽绒、棉服、派克、大衣。
- 中厚档外套 query 禁止羽绒、派克、厚大衣；不要回退成薄开衫/薄风衣。
- 下装、鞋的具体形态（裙/裤、单鞋/运动鞋）写给风格，天气不改写。
- 不写春、夏、秋、冬，不写保暖、凉快、防风；颜色可按风格需要写。
- 凉及以下不检索凉鞋。

## 修正项
| 条件 | 调整 |
|---|---|
| 小雨、阵雨、雷阵雨、中雨 | 鞋避开麂皮、帆布、浅色款；下装避开拖地长裤和长裙。不因此把外套直接改成厚外套 |
| 大雨、暴雨 | 在上一条基础上：优先防水鞋靴，下装选九分或收口款 |
| 雪、雨夹雪 | 鞋改为防滑保暖靴；外套改用冷档的大衣、棉服 |
| 风力 ≥ 4 级（「≤3级」不算） | 仍用该档外套厚度，不新增羽绒服；轻薄飘逸下装注意压住，不因此改成必须长裤 |
| 湿度 ≥ 80% 且 ≥ 26℃ | 速干透气面料，避免厚牛仔等贴身闷热款 |
| 湿度 ≥ 75% 且 ≤ 25℃ | 体感偏凉，外套不要省 |
