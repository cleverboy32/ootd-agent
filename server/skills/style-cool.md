# 潮酷/甜酷/街头风格定义 (Street Cool & Functional Style)

潮酷风的核心是“极端量感对比”与“材质硬度碰撞”，追求利落、张扬且富有张力的视觉轮廓。
绝对禁止：全身宽松无比例（臃肿塌房）、全身合身无造型感、全套同质化浅色、汉服/珍珠堆叠、两件及以上夸张印花。

## 1. 核心比例与量感 (Proportion & Silhouette)
- **单一夸张量感原则**：全身必须且**仅能有 1 处**量感夸张（肩部/上衣廓形、或下装裤脚），其余部分必须收拢：
  - **路径 A（上宽下利落）**：落肩宽松廓形外套/棒球服/连帽卫衣 + 顺直直筒裤/工装束脚裤（女性可为包臀短裙）。
  - **路径 B（上短下宽）**：
    - **女性**：短款/露脐上衣 + 高腰超宽阔腿裤/高腰大口袋工装裤。
    - **男性**：切齐腰线的短款硬朗外套（如短款机车皮衣、短夹克） + 重磅阔腿工装裤/大口袋弯刀裤。
- **绝对禁止**：全身上下同时宽松（臃肿无形）或全身上下同时修身紧身（失去街头潮感）。
- **外套量感**：外套必须作为整套搭配唯一的量感来源或保持干练结构。禁止在宽松连帽卫衣外叠加同样超大宽松的无结构大衣。

## 2. 配色与图案 (Color & Pattern)
- **硬核块面与高对比度**：必须有一块大面积深色（黑色、炭灰、深藏青）或高对比色块压阵，禁止全身低对比度的浅粉、浅米色。
- **性别与风格分支规范**：
  - **女性（甜酷特别规范）**：若用户明确点名“甜酷风”，“酷”占 80% 的轮廓与基调，“甜”仅作为 **10%-20% 的小面积调味**（如浅粉色内搭、粉色棒球帽或小面积甜美元素）。绝对禁止全身浅粉或蕾丝堆叠。
  - **男性/通用街头机能**：聚焦于冷感工业色（黑色、水泥灰、橄榄绿、做旧蓝）与金属冷光质感，拒绝无意义的碎花或粉嫩色块。
- **图案唯一性**：大印花、串标、字母 Logo、反光条或拼接元素**全套仅限 1 件**。

## 3. 面料与硬度碰撞 (Fabric & Texture Contrast)
- **软硬面料对比**：必须包含至少 1 件【硬质/结构感面料】（如：水洗牛仔、重磅皮革、机能尼龙、防风面料、重磅硬挺纯棉），与另一件相对柔软的面料形成张力。
- **面料禁区**：禁止全身毛绒、禁止全身无结构的薄软面料、禁止亮面雪纺/薄纱。

## 4. 鞋履与配饰 (Shoes & Accessories)
- **造型感鞋履（潮酷灵魂）**：
  - **女性**：厚底马丁靴、切尔西靴、厚底复古老爹鞋、高帮板鞋。
  - **男性**：重磅大头皮靴、厚底马丁靴、复古机能老爹鞋、高帮滑板鞋/面包鞋。
  - **通用禁区**：绝对禁止玛丽珍鞋、细带凉鞋、毛绒鞋、软底浅口豆豆鞋/平底鞋。
- **配饰规则**：配饰控制在 1-2 件（如：金属粗链条、机能扣腰带、银色冷感耳环/戒指）。**帽子与墨镜绝对不同时出现**（除非用户点名要求）。
- **包袋规范**：具有结构感或机能感的包袋（如：尼龙胸包、斜挎机能包、金属扣斜挎包/腋下包），包身紧贴身侧。

## 5. 多方案推荐规范 (Multi-Option Rules)
当需要提供 2 套方案时，必须满足：
- **比例与品类互斥**：
  - 一套必须采用【路径 A：上宽下直/下短（如廓形棒球服/卫衣 + 直筒裤/束脚裤/短裙）】。
  - 另一套必须采用【路径 B：上短下宽（如短款皮衣/夹克 + 高腰工装阔腿裤/弯刀裤）】。
- **拒绝同质化**：绝对禁止两套方案轮廓相同仅换颜色（如黑色工装裤换成灰色工装裤）。

## 6. 检索生成逻辑 (Search Query Guidelines)
- **Query 拼接**：所有槽位的 Query 必须包含`潮酷`、`甜酷`或`街头` + 性别词 (`男` / `女`) + 明确比例/轮廓（如`潮酷男 廓形棒球服`、`街头男 高腰工装阔腿裤`）。
- **通用天气适应逻辑**：
  - **有天气细则时**：厚薄听从天气要求（寒冷天气自动检索重磅皮革外套、短款羽绒服、厚底皮靴），但潮酷规则锁定硬朗碰撞与量感对比。屏蔽汉服、珍珠多层、玛丽珍鞋、软塌毛呢长裙。
  - **无天气细则时**：默认检索四季通用的基础潮酷单品（潮酷廓形卫衣/短外套、高腰工装裤、厚底马丁靴/老爹鞋）。
