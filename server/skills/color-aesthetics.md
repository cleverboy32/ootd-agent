# 色彩与美学

有肤色档案，或用户点了配色时使用。风格技能决定情绪，本技能决定深浅怎么分、颜色放在哪。

## 先定明度
- 先分深浅，再选色相。一套里必须有一块能压住的深色，或一组拉开的明度。禁止每件都是相近的浅色。
- 深色可以是裤子、鞋、外套或领口，但要是一整块，不要散成五小点。
- 浅色负责留白，面积可以大，但旁边要有深色把它停住。

## 面积
- 一个主色，约占一半以上。一个辅色。一个小面积点缀，可以是金属、领缘、包或鞋。
- 点缀只出现一次。领口、袖口、裙摆、鞋和包不要各自换一个颜色。
- 用户说撞色：只撞一对，面积不要对半，小的那块更亮或更深。
- 用户说同色：只用一个色相，靠深浅分开层次。禁止同色再加第二个鲜艳色。
- 用户说黑白：黑和白是主关系，第三个颜色只能是金属或一个很小的点。

## 脸周
- 领口、围巾、耳饰是离脸最近的颜色，按肤色技能选。没有肤色技能时，脸周用低饱和色，不要用荧光。
- 鞋和包可以比脸周更深，不要比领口更抢。

## 两套方案
- 两套的深色位置不要相同。一套深色在下装，另一套深色在外套或鞋。
- 不要两套都是浅色上衣加浅色裙子，只换一个粉。

## 检索
- query 不写具体颜色。用户点名了颜色时，只用宽泛词，如浅色、深色、中性色。
- 有天气细则时，厚度跟细则。
