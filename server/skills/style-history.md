# 考据派汉服与特定历史朝代服饰定义 (Historical & Authentic Hanfu Style)

“正经”古代服饰的核心是“严格遵循历史形制骨架”、“穿着严整垂裳肃穆”与“面料纹理的历史真实感”，追求历久弥新的高质感。
**核心原则：绝对不允许模糊核心领型、绝对不允许袖长不过腕、绝对不允许下摆高于脚踝露出光腿/脚踝（汉裤/长裙与皂靴/弓鞋是服饰完整的前提）。**
绝对禁止：影视古装戏服混淆形制、五分袖/七分袖袍服/短衫、下摆/裙摆在膝盖露出小腿肚、软面一脚蹬布鞋、现代混搭（如牛仔裤、卫衣）、高饱和荧光色、影视影楼感大面积薄纱。

## 1. 核心形制与五大古代通用风格 (Five Essential Historical Styles)

先按用户语义锁定下列之一，再写形制与氛围；禁止五种风格混成「泛古装逛街」。氛围四行必须落到方案字段：`overall_concept`（气质）、单品色与 description（配色/点睛）、`background`+`model_pose`（画面）。考据叠穿默认 `inner_visibility=collar_only`；仅当形制本身门襟打开（如对襟褙子有意敞穿）才填 `open`。

### 通用形制与叠穿硬约束
- **叠穿硬约束（古代本就穿几层）**：全套上装至少 **2 层可见衣物**（如中衣/交领衫 + 外层短打/褙子/袍；或中衣 + 袍）。**禁止**只给一件单薄短袖/中袖外衣当全身上装。外层袖长仍须盖至手腕；内层领缘可在交领处微露。
- **前襟完整性硬限（防风衣化裂开）**：袍服/长衫/短打在 `collar_only` 时前襟须完全闭合（交领叠压或圆领扣合），**严禁**画成敞开大衣/风衣裂开。

### 风格分类一：武侠/侠客劲装风 (Wuxia & Martial Arts)
- **定位**：干练利落、行走江湖的侠客/刺客/镖师风格。
- **男性形制**：中衣 + 窄袖交领短打/裲裆，**袖口必须绑定【紧致皮革/布质护臂】**，腰间紧束【革带/蹀躞带】，内搭汉裤收于【高帮皮革皂靴】内。
- **女性形制**：中衣 + 窄袖交领干练短衫 + 护臂 + 褶裤/宋裤 + 高帮靴，全身无赘余垂饰，利落飒爽。
- **绝对禁止**：“短袖罩长袖”的店小二/打杂感假两件、宽松塌垮的塌袖、百姓跑堂围裙感。
- **氛围气质**：风尘利落、身轻步稳，像赶路或驻足观望的江湖人，不是市井店员。
- **配色配方**：主色深靛/墨青/炭黑压阵；内衬月白或浅灰仅领缘一线；点缀最多一处深棕革件。
- **点睛符号**：护臂与蹀躞/革带二者至少落实一件写入 selected_items（不可只写在文案里）。
- **画面氛围**：青石巷或驿道侧光、尘意薄雾；姿态前倾赶路、手按革带或微侧观望。禁止空泛「开心逛街」。

### 风格分类二：明制飞鱼服/曳撒/官服风 (Ming Dynasty Formal & Guards)
- **定位**：皇家仪仗、锦衣卫、高规格宴饮与端庄官服风格。
- **男性形制**：明制曳撒/飞鱼服/贴里，胸前与袖口带有精美龙纹/飞鱼纹【补子】，腰下打褶，腰系【硬质质感革带】。
- **女性形制**：明制立领/交领织金长袄 + 胸前云肩/补子 + 织金马面裙（裙长直达脚踝盖住鞋面）。
- **氛围气质**：仪仗肃立、权柄在身，overall_concept 写官仪或禁卫气，不要写成日常便装。
- **配色配方**：主色大红/深藏青其一大面积压阵；辅色玄黑革带；织金纹样只落在补子或裙门一处。
- **点睛符号**：胸前居中补子（飞鱼/云肩/织金）必须写进外袍 description，位置与纹样可辨。
- **画面氛围**：砖石廊庑、宫墙影壁或厅堂柱础，正面或微侧端立；光线干净偏冷。禁止市井摊贩街景。

### 风格分类三：唐宋圆领袍/名士官风 (Tang/Song Round-Collar Robe)
- **定位**：唐宋时期文人雅士、朝堂官员、世家子弟的典雅风格。
- **男性形制**：内搭立领中衣 + 外穿重磅织锦/香云纱【圆领袍（盘领）】，右侧盘扣扣合，下摆盖至脚踝上方 3cm，下穿汉裤，脚踩【黑色方头皂靴】。
- **女性形制**：唐圆领袍（女穿男装）或宋制圆领大袖长衫，端庄挺拔。
- **氛围气质**：沉稳世家/名士气度，垂裳有序，不剑不履张扬。
- **配色配方**：主色朱砂/藏青/檀褐选一作袍身；内衬浅月白仅领缘；皂靴与革带深色收头。
- **点睛符号**：圆领盘扣扣合 + 袍身暗纹织锦（团花/云纹）写进 description；禁敞开裂襟。
- **画面氛围**：石阶庭院、影壁或廊下，站姿端正双手自然；暖调晴光。禁止武侠风尘尘土感。

### 风格分类四：宋制雅致风 (Song Dynasty Elegance)
- **定位**：清雅文气、茶会出游、极具东方松弛感的日常风格。
- **男性形制**：中衣 + 宋制长褙子/直身 + 宽腿宋裤 + 皂靴。
- **女性形制**：直领对襟长/短褙子 + 抹胸 + 墨绿/米白百迭裙/宋裤。
- **硬性要求**：褙子下摆高开衩，但**内搭汉裤/百迭裙必须长至脚踝**，严禁露出光腿。
- **氛围气质**：清雅松弛、茶会出游，overall_concept 偏文气闲适，不要官仪也不要江湖杀气。
- **配色配方**：外层浅米/月白/浅灰与下装墨绿/炭青形成浅深对比；禁止全身同质浅杏堆叠。
- **点睛符号**：直领对襟褙子开衩结构 +（女）抹胸层次或（男）直身层次须写清；可加一枚小玉佩/香囊。
- **画面氛围**：茶寮窗格、竹影庭院或碎石小径，侧身闲立或缓步；柔和散射光。禁止宫墙仪仗与驿道风尘。

### 风格分类五：魏晋/秦汉高古风 (Wei-Jin & Han Ancient Scholar)
- **定位**：仙气飘逸、竹林名士、史诗高古风格。
- **男性形制**：汉代直裾深衣 或 魏晋交领重磅大袖衫 + 汉裤，腰系宽博古带。
- **女性形制**：汉代曲裾深衣（三重领叠压） 或 魏晋大袖衫 + 齐腰襦裙，下摆如喇叭花般覆盖脚踝。
- **氛围气质**：高古飘逸、名士出尘，concept 写竹林清风或深衣垂袂，忌影楼仙侠糖霜感。
- **配色配方**：主色青灰/月白/玄褐沉静；大面积一层深色腰带或下裳压阵；禁高饱和荧光与满身金绣。
- **点睛符号**：广袖垂感或曲裾三重领叠压必须写进 description；宽博古带收腰。
- **画面氛围**：竹林雾感天光、溪石或空亭；衣袂微动的站立或缓步。禁止厚妆影楼大面积薄纱堆叠。

## 2. 配色与面料压阵规范 (Color & Pattern Control)
- **色彩主次与沉静压阵**：确定 1 个主色调（大地色系/矿物色系为主）。全套**必须至少有 1 处大面积深色压阵**（深藏青、墨黑、深炭灰、浓咖啡色、墨绿、朱红），通常落在领缘、裙门/汉裤或袍身。
- **图案唯一性与刺绣占比**：大面积印花/绣花**仅限 1 处**（领缘、裙门、袖口或胸背补子选一）。刺绣面积**严格小于衣身的 15%**，禁止满身满绣。
- **纹样聚焦**：选用暗纹织锦、四神纹、团花纹、祥云暗纹、水墨淡彩印花。绝对禁止大面积高饱和强烈撞色。

## 3. 面料的历史感表达 (Historical Texture & Fabric)
- **主角面料肌理**：外层必须显选用有结构克重、具有真实组织肌理的面料（如：重磅香云纱、织锦缎、精纺羊毛毛呢、重磅棉麻、法兰绒）。
- **面料禁区**：廉价化纤化缎、透光薄纱（魏晋广袖除外）、高光亮面尼龙、易皱塌塌的面料。保暖只能内衬加厚（如真丝夹棉）。

## 4. 鞋履与配饰规范 (Shoes & Accessories)
- **鞋履硬性限定（正经灵魂）**：
  - **男性**：袍服/劲装必须搭配**【中式方头皂靴 / 黑色高帮皮革皂靴】**。
  - **女性**：必须搭配**【中式翘头履 / 方头复古平底皮鞋 / 缎面绣花鞋】**。
  - **通用禁区**：绝对禁止软面一脚蹬布鞋、运动鞋、玛丽珍鞋、毛绒拖鞋、厚底雪地靴、高跟鞋。鞋面必须干净平滑。
- **配饰减法（总量不超过 2-3 件）**：
  - **男性**：硬质皮革革带/蹀躞带（劲装必选）、发簪/发冠/发绳、腰佩/香囊（挂于革带）。
  - **女性**：发簪/发钗（严禁堆叠大面积假花/流苏）、压襟（挂于右衽/胸前扣）、侧边小香囊/玉佩。
  - **配饰禁区**：发冠步摇项链同时堆叠、汉服交领处佩戴大项链、现代提包/眼镜、现代皮带扣。
- **点睛优先于堆饰**：五种风格的「点睛符号」占配饰名额；宁少而可辨，勿无符号只堆发饰。

## 5. 多方案推荐规范 (Multi-Option Rules)
当需要提供 2 套方案时，必须满足：
- **组合与朝代/场合异构**：
  - **男性**：一套为【正式圆领袍/飞鱼服（内衬中衣）+ 汉裤 + 皂靴】，另一套为【侠客劲装（配护臂与蹀躞带）+ 汉裤 + 皂靴】。
  - **女性**：一套为【明制立领/交领短衫 + 织金马面裙】，另一套为【宋制对襟褙子 + 抹胸 + 百迭裙/宋裤】。
- **氛围也要异构**：两套的 `background`/`overall_concept` 不得同为「古镇逛街」；须对应各自风格的画面氛围。
- **禁止微调敷衍**：绝对禁止两套方案仅在同质化浅色（如粉色、米白、杏色）之间切换。

## 6. 检索与 Prompt 生成逻辑 (Search Query & Prompt Guidelines)
- **Query 拼接**：所有槽位的 Query 必须包含`正统汉服`、`考据汉服`或明确`朝代服饰` + 性别词 (`男` / `女`) + 明确特定历史形制 + 风格氛围词（与所选分类一致，如`侠客`/`飞鱼服`/`圆领袍`/`宋制褙子`/`魏晋大袖`）+ 硬性正向词（`长袖到手腕`、`裙长/下摆长至脚踝`、`内穿汉裤`、`搭配皂靴/翘头履`）。上装检索须覆盖内层与外层（如`中衣`+`短打`/`褙子`），禁止只搜一件单穿外衣。点睛槽位 Query 须点名符号（如`护臂`、`蹀躞带`、`织金补子`）。
- **Prompt 硬性负向词挂载 (Negative Prompt)**：
  `短袖, 半袖/五分袖, 露腿, 裸露双腿, 及膝长裙/及膝短裤, 浴袍, 睡衣, 敞开式大衣/风衣, 前襟割裂/分列的外套, 敞开式前襟, 未扣合/未扣扣子, 店小二/跑堂, 杂役/仆从服饰, 围裙, 拖鞋, 现代眼镜, 现代皮带扣, 塑料质感配饰, 低画质, 模糊`
