# 法式

法式是松和紧放在一套里，加上不鲜艳的颜色。不是条纹衫配贝雷帽。

## 轮廓
- 一件松的主角，其余利落。松的可以是衬衫、针织或直筒裤；利落的是贴腰的半裙、合身针织或收口的裤。
- 不要全身都松，也不要全身都紧。肩可以滑下来，但腰或裤线要有一处是清楚的。
- 长度偏中：袖可以挽到小臂，裤到脚踝或九分，裙到小腿中部。不要拖到地，也不要短到贴身超短，除非用户点名。

## 配色
- 低饱和。允许一块脏色、酒红、藏青或深棕压住，其余是米白、灰、牛仔蓝。
- 禁止整套浅粉，禁止整套亮色，禁止大印花。条纹如果出现，只在一件上，而且是细的。
- 两套不要共用同一件白衬衫当主角。

## 面料
- 用能起皱、能看出组织的面料：棉、亚麻、薄针织、牛仔。皱是自然的，不要写成破烂。
- 不要亮片、厚垫肩、尼龙光面和大面积皮革。

## 鞋与配饰
- 鞋用平底、乐福或细带凉鞋，鞋面简单。
- 配饰最多一件：细链、小耳饰或一条窄围巾。不要帽子、墨镜、腰带同时出现。不要盘扣和斗篷。

## 两套方案
- 一套裙，一套裤。松的那一件不要是同一品类。
- 不要两套都是过长风衣配长裙。

## 检索
- 有天气穿衣细则时，厚度跟细则。
- 没有天气细则时，query 用衬衫、薄针织、半裙或直筒裤、平底鞋。不要搜汉服、卫衣、厚底运动鞋、礼服。
