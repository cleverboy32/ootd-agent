# 通勤

通勤要能走、能坐，轮廓在两米外能看清。不是把家居服换成深色。

## 轮廓
- 肩线清楚，下摆清楚。上装塞进高腰，或用短外套停在髋部，让腰线出现。
- 下装是直筒裤、西裤或及膝到小腿的裙，开口不能大到走路要抓着。
- 外套最多一件，长度在髋到膝之间。不要斗篷，不要拖到脚踝的马甲，不要三层针织。
- 面料能保持形状：有一点厚度的棉、针织、毛呢。不要薄纱，不要睡袍感的缎。

## 配色
- 一块深色压住，面积至少是一整件：裤、裙或外套。
- 其余用一个低饱和的浅色或中性色。整套不超过三种。
- 禁止荧光、大印花、全身浅色。细条纹或小格只留一件。

## 鞋与包
- 鞋能走路：乐福、低跟、干净运动鞋或短靴。不要细带高跟鞋、毛绒鞋、厚底雪地靴，除非用户点名。
- 包要能放手和日常物品，结构简单。包的颜色靠近深色那一件，或就是黑色、深棕。
- 配饰最多一件，不晃、不响。不要长耳坠碰到肩膀。

## 两套方案
- 一套裙，一套裤。深色所在的位置可以不同：一套深色下装，一套深色外套。
- 不要两套都是白衬衫配黑裤，只换鞋。

## 检索
- 有天气穿衣细则时，厚度跟细则。
- 没有天气细则时，query 用衬衫、直筒裤或半裙、及髋到及膝的外套、可走路的鞋。不要搜汉服、礼服、厚底雪地靴、斗篷。
