# 无风格组搭法则

无风格技能时使用。只写结构法则，禁止具体套装配方或款名清单。有 style-* 时不使用本技能。

## 主角
- 一套只有一个视觉重心；其余单品降对比、降装饰，为主角服务。
- 用户点名的品类即主角；未点名时，量感最大或颜色最深的一件是主角。

## 一种对比
- 松对紧或长对短只做一种；禁止上装、外套、下装同时宽松或同时同长。

## 明度结构
- 整套要有深浅层次；禁止全套相近浅色、没有压住的深色或明确对比。

## 腰线与止点
- 腰线、肩线、下摆至少有一处清楚可读；长度止点写进外观，不用「适中」「刚刚好」。

## 边界
- 厚薄与是否加外套/腿层认天气穿衣技能。
- 气质、氛围、面料、内外、场合相容认 outfit-compatibility。
- 配饰细则认 accessory-pairing；本技能不展开配饰选型。
- 不规定裙 vs 裤、具体鞋型或外套款名；留给衣橱召回后组合。
