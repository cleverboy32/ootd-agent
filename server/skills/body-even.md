# 五五分

上下身长度接近、腰线看起来在正中时使用。目标是把视觉腰线从中点挪开。

## 比例
- 不要让上衣下摆、外套下摆和裙子的腰停在同一个中点。这些线叠在一起，五五分会被强调。
- 把腰线抬高：高腰下装，上衣塞进腰头或裁到腰以上。腿的起点上移，上身看起来变短。
- 或者把上身拉长成一条：深 V、长门襟、同色的上衣和裤子连成一条，腰部不另做一条横线。两种做法选一种，不要一套里又抬腰又加横线。
- 下装长度走到脚踝，或明确停在膝上。停在小腿中部会再切出一段，比例更碎。
- 外套和上衣的长度必须差一截。短外套配长下装，或长外套敞开、里面的上衣明显更短。

## 不要
- 上下各占一半的箱型：正好盖住臀的上衣，配正好到膝的裙子。
- 宽腰带系在正中，把身体切成两段相等的色块。
- 上下两种对比很强的颜色各占一半面积。深浅可以有，但面积不要对半。

## 检索
- 有天气细则时，厚度跟细则。
- query 用高腰、踝长裤或长裙、短于腰线的上衣。不要搜低腰、盖住臀的长 T、膝下半截裙。
