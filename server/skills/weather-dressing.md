# 天气穿衣细则

按「三明治」管**大类层次与厚薄**：上装（内→中→外）与下装（裤内层→外裤，或裙/短七分 + 可见腿层）对等约束。  
**不管**裙还是裤的款式审美、开衫还是风衣外形、什么颜色——那些交给风格技能与场合。  
厚薄层级的适穿 ℃ 与衣橱单品 `tempMin`/`tempMax` 同语义：**单件单独穿着**合适的温度，不是叠穿后的体感。

## 使用步骤
1. 从【今日穿搭意图】读取出门时段的天气。温度区间保留两端。已知出门时段的分时温度时优先用对应读数。
2. **定档以服务端槽温区表为准**。有对应时段的体感温度时按体感，否则按气温。风、湿度、降雨用于材质、防护和穿脱提示。
3. 其余 Override（风格豁免厚鞋、雨雪材质、裤内层 vs 可见腿层等）仍按文末表叠加
4. 用户点名某层次（如不要外套、只要短袖、就要短裙）时，按用户要求，优先于本表
5. 用户说冷、外套不够暖：外套只升相邻一档。禁止从薄档直接跳到羽绒服、厚大衣
6. 据此决定要不要外套槽、上装/下装厚薄、是否开 `inner_bottom` 或 `legwear`。reason 用实际温度和体感说明，不得出现「档」「档位」「修正项」「细则」或表中的档位名称

## 温度档位（层数公式 | 上装三明治 | 下装）

| 档位 | 温度 | 层数公式 | 上装三明治（槽） | 下装与鞋 |
|---|---|---|---|---|
| 炎热 | ≥ 28℃ | 1 层：单穿透气基础层 | 只开 `top`（短袖等）；禁 `inner_top`/`outerwear`；禁针织与长袖外套 | 薄下装；无 `inner_bottom`/厚腿层；鞋偏透气（风格豁见 Override） |
| 微暖 | 23–27℃ | 1～1.5 层：短袖/背心 + 超薄防晒外，或单穿薄长袖 | `inner_top`+`outerwear`（薄外）；无中间层 `top` | 薄下装；鞋常规休闲闭合即可 |
| 舒适 | 18–22℃ | 2 层：薄打底/衬衫 + 轻薄防护层 | `inner_top`+`outerwear`（薄西装/开衫/风衣/牛仔夹克）；无中间层 | 常规下装；鞋常规休闲闭合 |
| 微凉 | 12–17℃ | 2 层：打底 + 春秋夹克/常规外套 | `inner_top`+`outerwear`（夹克等）；**无**中间层 `top` | 常规下装须**封口**（禁九分露踝）；裙+薄袜；鞋常规休闲闭合 |
| 凉 | 6–11℃ | 3 层：贴身打底 + 保暖中层 + 防风大衣/短羽绒 | `inner_top`+`top`(厚毛衣)+`outerwear`(大衣/轻暖羽绒) | 厚下装或裙+厚可见打底；鞋常规休闲闭合；禁光腿 |
| 冷 | 0–5℃ | 3 层重磅：薄贴身发热底层 + 厚毛衣 + 中长羽绒/厚呢大衣 | `inner_top`(薄贴身发热)+`top`+`outerwear`(严冬外) | 常规偏厚或偏厚的全长外裤 + `inner_bottom`（薄速干/发热内搭裤）；裙/短/七分开 `legwear`；鞋偏保暖；上宽下紧 |
| 寒冷 | &lt; 0℃ | 3～4 层：薄贴身发热底层 + 抓绒/厚羊绒 + 极寒长羽绒 + 配件 | 同冷档三槽；配件（围巾/冷帽/手套）按需 | 冬厚全长外裤 + `inner_bottom`；裙/短/七分开 `legwear`；洋葱式易脱中层 |

### 跨档温度

- 较暖端决定去掉可脱层后的基础穿法，较冷端决定外层防护。按服务端表选槽，每套单品只选一次，在 reason 里说明加哪一层、脱哪一层。
- 例如 10–18℃，可用能独立穿的薄针织长袖、全长裤和可脱的挡风夹克。较冷时穿夹克，较暖时脱夹克。已知时段再写早晚或中午。

### 核心法则（写进搭配，不写进单品字段）

- **炎热**：上短下长或上宽下短；材质偏亚麻/天丝/真丝/薄棉；屏蔽针织与长袖外套。
- **微暖**：外搭须轻薄易收纳，应对空调温差。
- **舒适 · 脱衣体面**：脱掉外套后内搭必须能独立成立（忌破旧居家内衣打底）。
- **微凉 · 下装封口**：禁九分露踝；裤脚盖鞋面或中筒袜/短靴衔接。
- **凉 · 领口错落**：三层领口要有高低差，避免脖子堆砌。
- **冷 · 上宽下紧**：外套膨时下装收紧，防圆柱体。
- **寒冷 · 洋葱式**：有暖气地区中层优先开衫/拉链，方便室内散热。

## 检索 query
- **炎热**：只开 `top`；禁止 `inner_top` / `outerwear`。
- **微暖～微凉**：开 `inner_top` + `outerwear`；**禁止开 `top` 中间层**。
- **单档凉及更冷**：开 `inner_top` + `top` + `outerwear`。跨档按服务端表决定可脱层。
- **冷/寒冷裤装（全长外裤）**：开 `inner_bottom` + `bottom`；`inner_bottom` query 写薄贴身速干/发热内搭裤，禁止羊羔绒/加绒袜型打底用语。
- **冷档外裤已有 `inner_bottom`**：外裤选全长遮踝、能容纳薄秋裤、常规偏厚或偏厚的款式。服务端外裤候选参考温区为 5–14℃，query 和 target 描述叠穿与覆盖。成品配齐秋裤，按实际天气、风和户外时长选厚薄。
- **冷/寒冷裙装或外露小腿的短/七分裤**：开 `legwear`（可见打底/连裤袜）；**禁止开 `inner_bottom`**。
- 外套厚薄用词跟档走；薄档 query 禁止羽绒/派克/厚大衣。
- 微凉及以下：下装避免短裤、薄迷你裙（除非搭配可见腿层）；裙装补 `legwear`。
- 鞋：听服务端槽温区（温区倾向，不点名必须某鞋型）；炎热禁厚靴，冷/寒冷偏保暖（风格豁免见 Override）。
- 不写春夏秋冬字作 query 词；颜色可按风格写。

## 修正项（Override，高于档位默认）

| 条件 | 调整 |
|---|---|
| 风力 ≥ 4 级（「≤3级」不算） | 凉天已有外层优先选防风款；暖天优先透气、抗风的款式 |
| 湿度 &gt; 75% 且气温 &lt; 10℃ | 优先挡风，遇雨雪时注意外层防湿 |
| 风格为街头潮流/美式复古/运动休闲，或场景为逛街暴走 | **豁免** 28–32℃ 的厚鞋限制，可推网面老爹鞋或低帮板鞋 |
| 出门时段气温跨档 | 按服务端表选择基础穿法和可脱防护层；在同一套里说明穿脱 |
| 小雨、阵雨、中雨 | 鞋避开麂皮/帆布/浅色；下装避开拖地长裤长裙 |
| 大雨、暴雨 | 优先防水鞋靴；下装九分或收口 |
| 雪、雨夹雪 | 防滑保暖靴；外套偏冷档大衣/棉服 |
| 湿度 ≥ 80% 且 ≥ 26℃ | 速干透气，避免厚牛仔贴身闷热 |
| 外下装为全长加绒裤、滑雪裤或同等隔热壳 | 开 `inner_bottom`（薄速干/发热内搭裤）；**禁止**再叠羊羔绒/加绒袜型 `legwear` |
| 外下装为毛呢短裤、厚短裤、七分裤等外露小腿，或裙装 | 开可见 `legwear`；**禁止**开 `inner_bottom` |
