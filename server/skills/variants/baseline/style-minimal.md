# 极简风格定义 (Minimalism / Quiet Luxury)

极简风格的核心是“件数克制”与“轮廓单一”，追求件数和轮廓形状的极小化，以及整体配色的极低明度差。
核心原则：极简不仅在于颜色（不是全灰色），更在于通过减少视觉干扰来突显面料质地与身体轮廓。
绝对禁止：多于三件衣服（除内搭）、多于一件配饰、撞色、印花、荷叶边/泡泡袖/不对称、腰带（夸张装饰腰带）。

## 1. 核心比例与件数 (Silhouette & Pieces Limit)
- **硬性件数硬限**：除内搭外，全套搭配【衣服】不得超过 3 件。
  - **路径 A（上装+下装+外层）**：衬衫/针织衫 + 长裤/半裙 + 外套/风衣/西装。
  - **路径 B（连衣裙/连体裤+外层）**：连衣裙/连体裤 + 外套/大衣。
  - **无外套方案**：连衣裙算 1 件；衬衫/针织衫 + 长裤/半裙算 2 件。单件上衣或连衣裙单穿即成立。
- **单一轮廓语言**：全身搭配必须且仅能有 1 个明确的轮廓语言（直筒 H 型，或轻微的 A 字型）。不要荷叶边、泡泡袖、不对称、抽褶同时出现。
- **腰线表达禁忌**：腰线必须内敛表达。仅能通过【塞衣角】（一处塞）或高腰西裤缝线显现。**绝对禁止**腰带加收腰加短款外套一起强调。
- **禁止叠穿**：绝对禁止披肩、斗篷和第三层外层。

## 2. 配色与图案 (Color & Pattern)
- **色彩块面原则**：全套采用**一种主色**占主导（可深可浅），禁止撞色。全套色彩明度差须极小。
- **收口深色规范**：允许在鞋、包或边口收缩处（深色面积小于主色）使用一块深色压阵，但明度差仍需克制。
- **色彩与图案禁区**：绝对禁止印花、大 Logo、全身同质化浅色（五件均为白/米色）、五件均为深灰。

## 3. 面料与质感贯穿 (Fabric & Texture Continuity)
- **贯穿原则**：全套方案（裤/裙或外套）须由**一种能看出肌理感**的主角面料（如：精纺羊毛、厚重水洗棉、平滑针织、重磅醋酸）贯穿。其余辅助单品剪裁须更安静、更无存在感。
- **面料禁区**：禁止亮片、镂空、大面积毛绒、光面尼龙、易皱面料、尼龙亮面（极短款保暖用除外）。保暖通过面料本身厚度（克重）提升实现。

## 4. 鞋履与配饰 (Shoes & Accessories)
- **鞋履推荐（注重克制行走）**：
  - **女性**：平底/中低跟乐福鞋、简洁德训鞋/板鞋、尖头/圆头/方头简洁短靴。
  - **男性**：极简皮质乐福鞋、方头/圆头德比鞋、极简德训鞋/切尔西短靴。
  - **通用禁区**：鞋头形状（尖/圆/方）全套统一，禁止反光、禁止毛绒。绝对禁止厚底运动鞋、玛丽珍鞋、绣花鞋、细带高跟凉鞋、拖鞋。
- **配饰减法**：全套配饰控制在 **1 件以内**。
  - **女性**：一条细金属链、一只小巧耳钉。
  - **男性**：极简薄款腕表、极细隐蔽皮带。
  - **通用禁区**：配饰必须细致、定点不抢占衣服焦点。
- **包袋规范**：包必须小且精致，结构简单，背在腰线以上，不破坏整体线条。

## 5. 多方案推荐规范 (Multi-Option Rules)
当需要提供 2 套方案时，必须满足：
- **比例与品类互斥**：
  - **女性**：一套必须为【H型裤装方案】，另一套必须为【A型/H型裙装方案】。
  - **男性**：一套必须为【H型外套+直筒裤（路径A）】，另一套必须为【单穿极简针织/衬衫+高腰西裤（无外套路径）】或两套采用不同的极简轮廓（一套 H 型、一套轻微 A 型/宽腿直线切线）。
- **色彩互斥**：两套方案的【主色】绝对禁止相同。禁止通过更换邻近色（如：将粉色针织换成杏色针织）或更换下装颜色（如：将粉色裤子换成杏色裤子）的敷衍设计。

## 6. 检索生成逻辑 (Search Query Guidelines)
- **Query 拼接**：所有槽位的 Query 必须包含`极简`或`极简主义` + 性别词 (`男` / `女`) + 明确轮廓/轮廓形状（如`极简主义女 精纺羊毛H型连衣裙`、`极简男 H型直筒西裤`）。
- **通用天气适应逻辑**：
  - **有天气细则时**：材质厚薄与面料克重听从天气要求（如寒冷天气自动检索厚呢羊毛衣、加厚西裤），但极简规则始终锁定单一 H 型轮廓与配色低明度。屏蔽汉服、大印花、厚底鞋、连帽卫衣。
  - **无天气细则时**：默认检索基础四季通用极简单品（极简衬衫、高腰直筒西裤、H型连衣裙/极简针织衫、简洁乐福鞋）。
