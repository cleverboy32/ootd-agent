# 配饰搭配法则

无风格技能时使用。只写配饰法则，禁止具体款名配方。有 style-* 时不使用本技能（配饰上限与允许池由风格技能负责）。

## 开槽
- 默认可不加 accessory。
- 正式/约会、用户点名配饰、或需要收束造型时再开 accessory 槽。

## 不抢主角
- 配饰对比度低于主角；无必要不加。

## 金属与材质统一
- 全身金属色系二选一，不混金银。
- 同套重复一个元素即可（同一金属、同一圆角或同一安静色），不要领、袖、包、鞋各自装饰一遍。

## 包与比例
- 包体量服务轮廓，不压短下装视觉长度；背负或手持位置写进外观。

## 数量默认
- 无风格时焦点配饰 ≤ 1–2。
- 帽与墨镜不同时堆叠（用户点名除外）。

## 边界
- legwear（打底袜等腿层）不是配饰；厚薄与袜层认天气穿衣技能。
- 鞋包与服装的氛围对齐认 outfit-compatibility；本技能只管开槽、数量与金属统一。
- 不写具体耳环/包款名清单。
