# 天气穿衣细则

按「三明治」管**大类层次与厚薄**：上装（内→中→外）与下装（裤/裙 + 必要时袜层）对等约束。  
**不管**裙还是裤的款式审美、开衫还是风衣外形、什么颜色——那些交给风格技能与场合。  
厚薄层级的适穿 ℃ 与衣橱单品 `tempMin`/`tempMax` 同语义：**单件单独穿着**合适的温度，不是叠穿后的体感。

## 使用步骤
1. 从【今日穿搭意图】的天气文本中读取温度、天气现象、风力、湿度；读不到的项跳过。温度须能解析出 ℃（含「约15-20℃」取中段体感）
2. 按温度落入唯一一个档位（边界值按表中区间归属，如 25℃ 属「舒适」，26℃ 属「偏热」）
3. 叠加命中的修正项；风力 ≥6 级时温度档位下调一档
4. 用户点名某层次（如不要外套、只要短袖、就要短裙）时，按用户要求，优先于本表
5. 用户说冷、外套不够暖：外套只升相邻一档。微凉升到凉 → 中厚；凉升到冷 → 厚。禁止从薄档直接跳到羽绒服、厚大衣
6. 据此决定要不要外套槽、上装/下装厚薄、裙装是否补袜。reason 用实际温度和体感说明，不得出现「档」「档位」「修正项」「细则」或表中的档位名称

## 厚薄层级 → 适穿 ℃（单件）

| 层级 | 适穿 ℃（含边界） | 典型品类 |
|---|---|---|
| 薄上装（短袖/无袖） | ≥22，无上限 | 短袖、背心、吊带 |
| 薄长袖/薄针织 | 12–22 | 薄衬衫、薄针织、毛呢薄衫 |
| 保暖上装 | 5–15 | 毛衣、厚针织 |
| 薄外套 | 13–25 | 薄开衫、牛仔外套、薄风衣、西装外套 |
| 中厚外套 | 8–17 | 摇粒绒、薄棉服、软壳、夹棉薄外套 |
| 厚外套 | ≤12 | 大衣、蓬松棉服、羽绒服、派克 |
| 薄下装 | ≥20，无上限 | 短裤、薄半身裙、薄连衣裙 |
| 常规下装 | 16–26 | 西裤、常规厚度长裤、常规裙 |
| 厚下装 | 10–20 | 毛呢裤/裙、厚牛仔、灯芯绒、加绒裤 |
| 薄～中打底袜 | 15–22 | 薄丝袜、薄打底 |
| 厚打底/连裤袜 | ≤15 | 厚打底袜、长筒袜、连裤袜 |

## 温度档位（上装三明治 | 下装三明治）

| 档位 | 温度 | 上装三明治 | 下装三明治 |
|---|---|---|---|
| 炎热 | ≥ 28℃ | 薄上装；不检索外套 | 薄下装；无打底 |
| 偏热 | 26–27℃ | 薄上装；室内空调可加薄外套 | 薄下装；无打底 |
| 舒适 | 22–25℃ | 薄上装或薄长袖；建议薄外套 | 薄～常规下装 |
| 微凉 | 18–21℃ | 长袖/薄针织 + 薄外套 | 常规下装；裙装可加薄袜 |
| 凉 | 13–17℃ | 保暖上装 + 中厚外套 | 厚下装，或裙 + 薄～中厚打底袜 |
| 冷 | 8–12℃ | 保暖上装 + 厚外套 | 厚下装，或裙 + 厚打底/长筒袜；禁止光腿 |
| 寒冷 | ≤ 7℃ | 保暖内搭上装 + 厚外套 | 厚下装 + 袜，或裙 + 厚连裤袜；禁止光腿 |

裙 vs 裤由风格决定；**走裙装或裸腿下装时，必须按上表补腿层**，不得冬裙光腿成套。

## 检索 query
- 天气约束：是否检索 `outerwear`、上装厚薄用词、外套厚薄用词、**下装厚薄用词**、凉及以下裙装时的 `accessory`（打底袜/长筒袜）。
- 外套：薄档用开衫、薄风衣、衬衫外套等；中厚档用摇粒绒、薄棉服、软壳、稍厚针织外套；厚外套（大衣、蓬松棉服、羽绒服）只在冷、寒冷两档。
- 薄档外套 query 禁止羽绒、棉服、派克、大衣。
- 中厚档外套 query 禁止羽绒、派克、厚大衣；不要回退成薄开衫/薄风衣。
- 凉及以下：下装 query 避免短裤/薄短裙；裙装路线必须另检索腿部保暖 accessory。
- 鞋的具体形态（单鞋/运动鞋）写给风格；凉及以下不检索凉鞋。
- 不写春、夏、秋、冬，不写保暖、凉快、防风作 query 词；颜色可按风格需要写。

## 修正项
| 条件 | 调整 |
|---|---|
| 小雨、阵雨、雷阵雨、中雨 | 鞋避开麂皮、帆布、浅色款；下装避开拖地长裤和长裙。不因此把外套直接改成厚外套 |
| 大雨、暴雨 | 在上一条基础上：优先防水鞋靴，下装选九分或收口款 |
| 雪、雨夹雪 | 鞋改为防滑保暖靴；外套改用冷档的大衣、棉服；下装偏厚 |
| 风力 ≥ 4 级（「≤3级」不算） | 仍用该档外套厚度，不新增羽绒服；轻薄飘逸下装注意压住或加袜层 |
| 湿度 ≥ 80% 且 ≥ 26℃ | 速干透气面料，避免厚牛仔等贴身闷热款 |
| 湿度 ≥ 75% 且 ≤ 25℃ | 体感偏凉，外套与下装厚薄不要省 |
