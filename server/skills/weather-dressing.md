# 天气穿衣细则

## 使用步骤
1. 从【今日穿搭意图】的天气文本中读取温度、天气现象、风力、湿度；读不到的项跳过
2. 按温度落入唯一一个档位（边界值按表中区间归属，如 25℃ 属「舒适」，26℃ 属「偏热」）
3. 叠加命中的修正项；风力 ≥6 级时温度档位下调一档
4. 用户点名要某品类（如短裤）时，该槽位按用户的品类写 query，优先于本表
5. 用户说冷、外套不够暖：外套只升相邻一档。微凉升到凉，仍是薄外套，可以写成风衣。禁止跳到羽绒服、棉服
6. 据此写检索 query 和选品。reason 面向用户，用实际温度、天气和体感说明依据（如「23℃ 傍晚有雾，体感偏凉」），不得出现「档」「档位」「修正项」「细则」或表中的档位名称

## 温度档位
上装、下装写具体种类。外套只分薄、厚，不逐件点名款式。飞行员夹克、连帽拉链衫、牛仔外套、西装外套都算薄外套。

| 档位 | 温度 | 上装 | 外套 | 下装 |
|---|---|---|---|---|
| 炎热 | ≥ 28℃ | 短袖、无袖 | 不检索外套 | 短裤、短裙、长裤 |
| 偏热 | 26–27℃ | 短袖 | 室内空调可检索一件薄外套 | 短裤、长裤 |
| 舒适 | 22–25℃ | 短袖、薄长袖 | 薄外套 | 长裤、中长裙 |
| 微凉 | 18–21℃ | 长袖衬衫、薄针织 | 薄外套 | 长裤 |
| 凉 | 13–17℃ | 卫衣、针织衫 | 薄外套，可含风衣 | 长裤 |
| 冷 | 8–12℃ | 毛衣、针织衫 | 厚外套（大衣、棉服） | 长裤 |
| 寒冷 | ≤ 7℃ | 毛衣、保暖内搭 | 厚外套（羽绒服、厚大衣） | 长裤 |

## 检索 query
- 上装、下装只写命中档的品类词。外套只表达薄或厚：薄外套用「薄外套、开衫、衬衫外套」这类宽词；厚外套只在冷、寒冷两档才写进 query。
- 不写颜色，不写春、夏、秋、冬，不写保暖、凉快、防风。
- 薄外套的 query 禁止出现羽绒、棉服、派克。
- 鞋的 query 用宽泛鞋类词，不要收成某一双的款式。凉及以下不检索凉鞋。

## 修正项
| 条件 | 调整 |
|---|---|
| 小雨、阵雨、雷阵雨、中雨 | 鞋避开麂皮、帆布、浅色款；下装避开拖地长裤和长裙。不因此把外套改成厚外套 |
| 大雨、暴雨 | 在上一条基础上：优先防水鞋靴，下装选九分或收口款 |
| 雪、雨夹雪 | 鞋改为防滑保暖靴；外套改用冷档的大衣、棉服 |
| 风力 ≥ 4 级（「≤3级」不算） | 仍用该档外套种类，不新增羽绒服或棉服；裙装避开轻薄飘逸款 |
| 湿度 ≥ 80% 且 ≥ 26℃ | 速干透气面料，避免厚牛仔等贴身闷热款 |
| 湿度 ≥ 75% 且 ≤ 25℃ | 体感偏凉，外套不要省 |
