# 暖调肤色

档案或用户原话是暖调、暖皮、黄皮时使用。只约束颜色，不改剪裁。

## 贴着脸
- 领口、围巾、耳饰用暖色：米白、杏色、驼色、暖棕、砖红、橄榄、金色。
- 白色用乳白或米白。不要用发蓝的白贴着脸。
- 黑色如果贴脸，用偏棕的黑，不要用发蓝的黑。更稳的做法是黑放在裤子或鞋，领口留暖色。

## 可以离脸远一点
- 冷蓝、冷灰、冷粉可以做裤子、包或外套下摆，面积不要升到领口。
- 荧光橙、大面积芥末黄会抢过皮肤，只留小面积。

## 金属与深浅
- 金属用金，或无金属。不要银饰贴着脸。
- 深浅仍按色彩技能：一套里要有一块深的暖色，不要全身米杏浅驼。

## 检索
- query 不写杏色、驼色这类具体色。用户点名颜色时才用浅色、深色、暖色。
- 有天气细则时，厚度跟细则。
