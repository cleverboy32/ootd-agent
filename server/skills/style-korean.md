# 韩系风格定义 (Korean Chic / K-Minimalism)

韩系穿搭的核心是“极端比例”与“利落块面”，追求极简、干净且显高显瘦的视效。
核心灵魂：无论是短上衣还是长大衣，整体搭配必须有明确的【高腰线】或【上短下长/上宽下利落】的比例呈现。
绝对禁止：模糊腰线、全身无腰线的臃肿叠穿（扣死长外套且内搭不塞腰）、全身浅色无深色压阵、大面积杂乱纹样。

## 1. 核心比例与剪裁 (Silhouette & Proportion)
- **绝对腰线/显高原则**：全身搭配必须至少有 1 处能明确看见高腰线，分为两种实现路径：
  - **路径 A（短款/短外套）**：
    - **女性**：短款上衣/短外套止于腰线附近或髋部以上，衔接高腰裤/高腰裙（直观上短下长）。
    - **男性**：切齐腰线的短款夹克/短羽绒/短款针织，或上装干净塞入高腰直筒裤内。
  - **路径 B（长外套/大衣）**：长大衣必须**敞开穿**（展示内部高腰/塞衣角比例），或通过**高腰带束腰**拉高腰线。
- **下装要求**：
  - **女性**：高腰直筒裤、高腰落地阔腿裤、高腰直筒/A字长裙（盖过鞋面或至脚踝，拉长腿部线条）。
  - **男性**：高腰微阔直筒西裤、垂坠感高腰落地裤、干净利落的高腰九分裤。绝对禁止低腰或掉档裤。
- **叠穿限制**：绝对禁止把长外套闭合扣死且无腰带、内部内搭不塞腰线导致的“无腰线直筒/臃肿感”。

## 2. 配色与图案 (Color & Pattern)
- **色彩块面原则**：必须形成明确的“浅色块”和“深色块”对比，块面划分清晰：
  - 上浅 + 下深（最基础显高比例）
  - 内浅 + 外深（外层为短外套/大衣）
- **色彩禁区**：禁止全身同质化浅色（如全身上下均为浅灰、米色、奶白而无深色收头）。全身【浅色】单品最多两件且需紧挨，剩余单品必须由一个深色压阵。
- **图案规范**：图案必须干净、克制。格子或细条纹全套仅限一件，禁止大面积印花混搭。

## 3. 面料与质感 (Fabric & Texture)
- **推荐面料**：纹理平整干净的针织、挺括棉质、精纺羊毛、垂坠感西装面料、直筒牛仔，以及**短款/超短款哑光羽绒（如短款面包服）**。
- **面料禁区**：汉服织锦、过长拖沓且无腰线的臃肿长羽绒、过于皱巴粗糙的面料、廉价光面化纤。

## 4. 鞋履与配饰 (Shoes & Accessories)
- **鞋履推荐**：
  - **女性**：极简运动鞋（如德训鞋/板鞋）、皮质乐福鞋、方头/尖头复古短靴。
  - **男性**：极简德训鞋、复古板鞋、黑色皮质乐福鞋、利落切尔西短靴。
  - **通用禁区**：绝对禁止拖鞋、厚底雪地靴、粗犷户外靴。
- **袜子规范**：袜子若露出，必须为净色短袜（黑/白/灰）。
- **配饰与包袋减法**：全套配饰不超过 2 件（如：小巧耳饰/细链、精致手表）。包袋必须小而有结构感，背在腰线以上，不抢占下装视觉长度。

## 5. 多方案推荐规范 (Multi-Option Rules)
当需要提供 2 套方案时，必须满足：
- **轮廓与品类异构**：
  - **女性**：一套必须为【短款裤装方案（如短上衣/短羽绒 + 高腰裤）】，另一套必须为【长款/裙装方案（如敞开式长大衣 + 高腰长裙）】。
  - **男性**：一套必须为【短款夹克/短羽绒 + 高腰直筒裤（上短下长）】，另一套必须为【敞开式长款大衣/风衣 + 挺括西裤（内搭显高比例）】。
- **拒绝同质化**：严禁出现两套方案均为无腰线长外套或仅更换颜色的敷衍设计。

## 6. 检索生成逻辑 (Search Query Guidelines)
- **Query 拼接**：所有槽位的 Query 必须包含`韩系`或`韩风` + 性别词 (`男` / `女`) + 明确长短比例（如`韩系男 短款夹克`、`韩系女 敞开式长大衣`）。
- **通用天气适应逻辑**：
  - **有天气细则时**：单品的材质厚薄与面料听从天气要求（如寒冷天自动检索短款羊毛外套、短款羽绒服或羊绒大衣），但韩系规则始终锁定“高腰线/显比例”的轮廓。屏蔽汉服、广袖、马面裙等非韩系元素。
  - **无天气细则时**：默认检索四季通用的基础韩系单品（韩系短上衣、短外套、敞开式大衣、高腰阔腿裤、高腰长裙、德训鞋）。
