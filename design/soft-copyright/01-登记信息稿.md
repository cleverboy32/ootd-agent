## 四、软件技术与功能说明（填表「主要功能」「技术特点」可照抄）

### 4.1 主要功能（至少 500 字，可直接粘贴）

```
本软件是一款面向个人用户的人工智能穿搭助手，核心目标是帮助用户基于自有衣橱完成日常穿搭决策，降低“今天穿什么”的选择成本。软件以 Web 应用形式提供服务，支持用户注册登录、会话保持、安全设置与访问控制；管理员或部署方可按邀请制方式限制完整对话能力的使用范围，便于内测与演示场景管控。

在个人形象与偏好方面，软件提供个人画像维护功能，用户可录入或更新体型相关描述、风格偏好、常驻城市或位置等信息。画像数据用于提升后续穿搭方案的贴合度，使推荐结果更符合用户真实穿着习惯与场景约束。软件同时支持对话历史管理，用户可新建会话、浏览历史消息并在上下文中继续追问，例如在已讨论某类单品后进一步询问搭配细节，减少重复澄清。

在数字衣橱方面，用户可上传服装单品图片，建立个人数字衣橱并对其进行浏览、查看详情、编辑元数据与删除等管理操作。系统对衣橱单品进行结构化存储与检索索引，为后续智能推荐提供可穿范围的数据基础。衣橱越完整，推荐越能贴近用户真实可搭配的单品集合，避免脱离衣橱的空泛建议。

在智能穿搭对话方面，用户可通过自然语言描述场合、天气、行程或单品需求发起咨询，例如通勤、约会、出行、聚会等场景。系统对用户意图进行识别与路由，提取关键要素；当信息不足时给出澄清问题；当需要基于衣橱出方案时，从用户数字衣橱中检索候选单品，并结合颜色、季节等约束进行筛选。随后生成穿搭方案与可读的中文建议文案，并以流式方式展示，提升交互体验。

在可视化方面，软件可根据穿搭方案生成上身效果图，并对生成结果进行质量相关处理或审核，降低明显错误出图对用户体验的影响。效果图与文案、方案一并呈现在对话消息中，便于用户直观判断是否采用该套搭配。综合来看，本软件覆盖账户与安全、个人画像、数字衣橱、对话式穿搭推荐、文案输出、效果图生成与会话管理等完整功能链路，形成从“管衣橱”到“问穿搭”再到“看效果”的一体化使用闭环。
```

### 4.2 技术特点（建议 100～300 字）

本软件采用 TypeScript / Next.js 全栈实现，服务端以多智能体流水线编排：Gatekeeper（意图路由）→ RAG（衣橱语义检索）→ Stylist（穿搭方案）→ Copywriter（文案流式输出）与 VisualDirector（效果图生成及审核）并行协同。衣橱检索支持向量相似度与颜色、季节等规则过滤；配套 Prompt 回归测试与全链路审计日志，保障输出质量可度量、可回归。运行于 Node.js 环境，支持主流浏览器访问。
