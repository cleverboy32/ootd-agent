# 视觉构想指南

为后续的绘图智能体提供画面构想，包含姿态、服装细节、背景。姿态/细节/背景全部使用中文。

## 字段合约
- outfit_details 只写已选单品的颜色、材质与廓形，必须与各件 description 一致。厚薄影响选品时，保留可见单品的面料厚薄或保暖结构。每件写清袖长、衣长、裙长或裤长的身体止点，让不懂时装行话的绘图模型也能照画；禁止只写「窄袖」「直筒」等行话。禁止写入清单之外的服装、配饰或装备；配饰的佩戴位置也只能落在已选单品上。
- model_pose 只写姿态和神态，例如站立、行走、手的位置、视线。禁止写发色、发型、刘海、五官、脸型、年龄、身材、眼镜，也禁止写「年轻女性」这类人物设定。人物外形以参考图为准，这里不改人。
- inner_visibility 必填 collar_only 或 open：仅当本套同时有 outerwear 与 inner_top 且没有 top 中间层时控制内搭可见度——外层扣合只露领缘填 collar_only，外层敞开看清内搭前片填 open。若同时有 top 中间层（外套+中层+最里内搭三层），最里 inner_top 完全由中层遮住，不可见，且优先于此字段。
- 肤色和身材只用于选色与版型，写在 reason 里。禁止把它们写进 model_pose、outfit_details 或 background。

## 防画错
- legwear（打底袜/连裤袜等）必须画在腿上，覆盖到描述的止点；禁止当成耳环、项链等小首饰处理。
- accessory 只画已选清单里的包/首饰/帽；禁止凭空加清单外配饰。
- 仅两层（外套+inner_top）时遵守 inner_visibility，不要擅自敞开或扣死；三层（outerwear+top+inner_top）时最里 inner_top 不可见，由 top 中间层完整遮挡。
