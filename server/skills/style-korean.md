# 韩系风格定义 (Korean Chic / K-Minimalism)

韩系穿搭的核心是“极端比例”与“利落块面”，追求极简、干净且显高显瘦的视效。
核心灵魂：无论是短上衣还是长大衣，整体搭配必须有明确的【高腰线】或【上短下长/上宽下利落】的比例呈现。
绝对禁止：模糊腰线、全身无腰线的臃肿叠穿（扣死长外套且内搭不塞腰）、全身浅色无深色压阵、大面积杂乱纹样。

## 写方案方式（合法集合）

1. **轮廓路径（每套必选恰好 1，写入 overall_concept：`路径=<名>`）**
   - **女**：`短款裤装`（短上/短外套 + 高腰裤） | `长款裙装`（敞开长大衣或长外套 + 高腰长裙） | `短款裙装`（短上 + 高腰及踝裙） | `长外套裤装`（敞开长外套 + 高腰直筒/阔腿裤）
   - **男**：`短款夹克裤装` | `敞开长大衣西裤` | `短羽绒/短针织+高腰直筒裤` | `无外套利落针织+西裤`
2. **主色块面（点名）**：上浅下深 | 内浅外深；全身浅色最多两件且须紧挨，须有深色压阵。
3. **出 1 套也要点名路径**；多套或 redo：**禁止**与上一套同一路径，禁止只换邻近色。

## 1. 核心比例与剪裁
- **绝对腰线**：全身至少 1 处可见高腰线（短款露腰线，或长外套敞开/束腰露出内部高腰）。
- **下装允许池（点名，非唯一）**：高腰直筒裤 | 高腰阔腿裤 | 高腰直筒/A 字长裙 |（男）高腰微阔西裤/九分裤。禁低腰掉档。
- **叠穿禁区**：长外套闭合扣死且无腰带、内部不塞腰导致无腰线臃肿。

## 2. 配色与图案
- 须有明确浅色块与深色块对比。
- 禁全身同质浅灰/米色/奶白无深色收头。
- 格子或细条纹全套仅限一件；禁大面积印花混搭。

## 3. 面料
- 允许池：平整针织、挺括棉、精纺羊毛、西装面料、直筒牛仔、短款哑光羽绒。
- 禁：汉服织锦、无腰线臃肿长羽绒、过糙皱巴、廉价光面化纤。

## 4. 鞋履与配饰（允许池）
- **女允许**：极简德训/板鞋 | 乐福 | 方头/尖头复古短靴（每套点名一类，redo 换类）。
- **男允许**：德训 | 复古板鞋 | 乐福 | 切尔西短靴。
- **禁**：拖鞋、厚底雪地靴、粗犷户外靴。
- 配饰 ≤ 2；包小而有结构，背在腰线以上。

## 5. 多方案
- 2 套：必须两个不同轮廓路径；严禁两套均为无腰线长外套或仅换色。

## 6. 检索生成逻辑 (Search Query Guidelines)
- Query 含`韩系`或`韩风` + 性别词 + **本套路径关键词**（如短款夹克 / 敞开式长大衣 / 高腰长裙）+ 长短比例。
- 有天气细则：厚薄听天气，轮廓锁高腰线；屏蔽汉服广袖马面等。
- **禁止**无路径点名时默认抄「短上衣+阔腿裤+德训鞋」固定串。
