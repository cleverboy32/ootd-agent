# 古风与汉服

汉服按形制搭配，不按现代「内搭 + 外套 + 半裙」叠。上衣下裙、深衣、袍，各自已经是完整一套。

## 形制
- 上衣下裙：衣长盖住裙腰。交领右衽、对襟或立领选一种，系带或盘扣写清楚。袖只选一种：窄袖、直袖或广袖，不要一件衣服上两种袖。
- 马面裙必须写前后裙门和两侧褶。裙门是平的，褶在两侧，裙长到脚踝。禁止写成开衩直筒裙、西装裙、鱼尾裙或普通百褶裙。
- 深衣、圆领袍、褙子是整件，不再加短袄，也不再加马面裙。
- 比甲只能作为这套形制里的一层，无袖、对襟，衣长写清楚。不要把现代毛衣背心或长大衣叫成比甲。
- 保暖写在面料和里衬上：夹棉、加绒、毛呢裙、织锦。不要再套斗篷、大衣、棉服、羽绒服、西装或连帽外套。

## 配色
- 先定一个主色，其余只留这个主色的深浅，或一个小面积对比色。
- 禁止短袄、长裙、外披全是杏色、浅驼、米白这类相近浅色。至少有一块深色，落在领缘、裙门、腰带或外层。
- 纹样只放在一个位置：领、裙门或袖口。不要衣身、裙子、鞋子同时大面积印花。

## 鞋与配饰
- 鞋用绣花鞋、方头布鞋或素面平底。不要运动鞋、玛丽珍、厚底靴。
- 配饰只留一件，贴着发型或领口：发簪、耳坠或一条短项链。不要多层珍珠压住交领，不要现代手提包当主角。

## 两套方案
- 两套用不同形制。例如一套上衣下裙，一套袍或深衣。不要两套都是短袄配长裙，只换豆沙粉和杏色。
- 场合改变的是颜色深浅和纹样多少，不改变「这是一套完整形制」。

## 检索
- 有天气穿衣细则时，厚度跟细则。
- 没有天气细则时，query 用袄、马面裙、褶裙、袍、深衣。不要搜大衣、棉服、羽绒服、运动鞋、卫衣。
