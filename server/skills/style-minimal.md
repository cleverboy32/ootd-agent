# 极简风格定义 (Minimalism / Quiet Luxury)

极简风格的核心是“件数克制”与“轮廓单一”，追求件数和轮廓形状的极小化，以及整体配色的极低明度差。
核心原则：极简不仅在于颜色（不是全灰色），更在于通过减少视觉干扰来突显面料质地与身体轮廓。
绝对禁止：多于三件衣服（除内搭）、多于一件配饰、撞色、印花、荷叶边/泡泡袖/不对称、腰带（夸张装饰腰带）。

## 写方案方式（合法集合）

1. **轮廓路径（每套必选恰好 1，写入 overall_concept：`路径=<名>`）**
   - **女**：`H型裤装三件`（上+裤+外层） | `A/H型裙装`（裙或连衣裙±外层） | `无外套裤装` | `无外套连衣裙`
   - **男**：`外套+直筒西裤` | `无外套针织/衬衫+高腰西裤` | `轻微A型/宽腿直线` | `单穿极简针织+长裤`
2. **主色（点名 1）**：须低明度差；多套/redo **主色不得与上一套相同**（禁止粉↔杏邻近敷衍）。
3. **出 1 套也要点名路径**；多套必须不同路径。

## 1. 核心比例与件数
- 除内搭外，衣服 ≤ 3 件。
- 全身仅 1 个轮廓语言（直筒 H 或轻微 A）；不要荷叶边/泡泡袖/不对称/抽褶并发。
- 腰线内敛：仅塞衣角或高腰西裤缝线；禁腰带+收腰+短外套同时强调。
- 禁披肩、斗篷、第三层外层。

## 2. 配色与图案
- 一种主色占主导；禁撞色；明度差极小。
- 允许鞋/包/边口一小块深色收口。
- 禁印花、大 Logo、五件全白米色、五件全深灰。

## 3. 面料
- 须有一件可辨肌理的主角面料（精纺羊毛、重磅水洗棉、平滑针织、重磅醋酸等）贯穿；其余更安静。
- 禁亮片、镂空、大面积毛绒、光面尼龙、易皱面料。

## 4. 鞋履与配饰（允许池）
- **女**：乐福 | 德训/板鞋 | 简洁短靴（尖/圆/方头统一）（点名一类）。
- **男**：乐福 | 德比 | 德训 | 切尔西。
- 禁厚底运动、玛丽珍、绣花鞋、细带高跟、拖鞋。
- 配饰 ≤ 1；包小而精致，腰线以上。

## 5. 多方案
- 2 套：不同路径 + 不同主色；禁仅换邻近色或只换下装颜色。

## 6. 检索生成逻辑 (Search Query Guidelines)
- Query 含`极简`或`极简主义` + 性别词 + **本套路径/轮廓词**（H型直筒 / A型裙 / 无外套针织等）。
- 有天气细则：克重听天气，轮廓锁单一 H/A 与低明度；屏蔽汉服、大印花、厚底鞋、连帽卫衣。
- **禁止**无路径点名时默认抄「衬衫+西裤+乐福」固定串。
