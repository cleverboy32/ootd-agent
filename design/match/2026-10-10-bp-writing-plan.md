## 核心叙事（三层结构，已确认方向）

- **价值层（C 端生活方式）**：解决「每天穿什么」的穿衣搭配烦恼，倡导「数字衣橱 + AI 私人造型师」的新生活方式——情感共鸣层，评委第一眼记住的标签
- **商业层（双轮变现）**：
  - 电商联合：穿搭推荐直达购买（CPS 导购分佣）、品牌合作、直播/内容电商场景接入、电商平台 ISV 插件
  - B 端 SaaS：面向服装电商/品牌的「AI 穿搭引擎」，核心价值 = 降退货率（行业 50%~60%、单次退货成本 16 元，有据可查）+ 提升连带率
- **愿景层（后期展望）**：技术演进、品类扩展、平台化生态（独立成章）

## 章节结构与写作要点

1. **项目概述** — 一句话定位（「AI 私人造型师，穿衣搭配新方式」）、C 端痛点场景（每天穿什么的决策烦恼、衣橱闲置率高）、**需求普遍性**（穿搭是全民高频刚需，覆盖日常办公、旅游出行、节假日聚会、商务场合等全场景）、解决方案、三大亮点
2. **行业与市场分析** — 全部用已核实的真实数据并标注来源：
   - 需求普遍性：穿衣搭配是每人每天的高频决策，场景横跨通勤、差旅、度假、节庆，天然高频高粘性
   - 大盘：服装 B2C 网零 2.38 万亿元（2025，中国纺联）；2026 上半年穿类网零同比 +6.2%
   - B 端痛点：女装线上退货率 50~60%（直播 80%+）、单次退货综合成本约 16 元、平台考核转向净成交
   - 赛道：中国虚拟试衣/AI 穿搭 2026 约 82.3 亿元、CAGR 46.7%、渗透率将破 28%、行业转向 SaaS 订阅
   - 政策契合：大赛「数字经济、人工智能研发及应用」方向
3. **产品与技术** — 基于项目真实架构写，不虚构：
   - 双模式产品形态（核心卖点）：对话模式（探索型需求，一问一答）+ 托管模式「穿搭计划」（日常场景免询问：按天气/行程/穿着历史定时生成今日/本周穿搭，推送穿搭图，用户照着穿即可；解决高频日常的决策疲劳与问答式产品的留存困境；多 Agent 管线全复用，仅新增触发层与推送层——架构前瞻性的实证）
   - 新生活方式体验场景（全场景覆盖，五个具象画面：日常通勤托管推送（不用问，照着穿）/ 差旅出行按目的地天气与行程打包（真实支撑：高德天气服务 + 季节过滤）/ 节假日聚会场景造型 / 度假旅游胶囊衣橱 / 购物前 AI 预搭配）
   - 产品形态与核心功能链路（对话 → 意图路由 → 衣橱检索 → 方案 → 文案 + 效果图）
   - 多 Agent 编排架构图（mermaid：Gatekeeper / RAG / Stylist / Copywriter / VisualDirector）
   - 工程化壁垒：Prompt 回归测试体系（`tests/prompts/`）、全链路审计日志（`log/*-audit.jsonl`）、双 Embedding 混合检索
   - 技术路线选择（应对「虚拟化如何真实」的预判）：生成式 2D 路线 vs 3D 建模路线的取舍逻辑（成本/上新速度/SaaS 化契合，行业正向生成式转向）；真实性工程保障 = Prompt 构建管线（`buildImagePrompt`）+ AI 审核闭环（`visual/critic.ts`、visual-audit 日志）；诚实边界：毫米级合身度为当前路线边界，归入风险或路线说明
4. **商业模式（双轮变现 + 分阶段路线图）** —
   - 商业化路线图（诚实分层，核心亮点）：第一阶段 C 端产品验证 + 托管模式「穿搭计划」上线（当前至近期迭代，订阅制起点）→ 第二阶段接入 CPS 联盟（淘宝联盟/京东联盟开放接口）跑通导购分佣 → 第三阶段依托园区资源试点 B 端 SaaS
   - 电商联合：CPS 导购分佣（推荐直达购买链接）、品牌合作与联名、直播/内容电商场景接入、电商平台 ISV 插件
   - B 端 SaaS：定价模型（订阅 + 调用量阶梯）、目标客户画像（腰部以上服装电商/品牌）、获客路径（产业带服务商/园区场景）
   - C 端订阅：**问答免费 + 托管收费**——订阅卖的不是提问次数，是「穿搭被接管」的穿搭计划服务（C 端付费逻辑的核心支撑）
   - 如实表述："产品架构已为商业化预留接口"（推荐结果为结构化单品数据）
5. **竞争分析** — 三类对手对比表：虚拟试衣方案商（重 3D 建模、交付重）、通用大模型（无衣橱数据与工程闭环）、传统穿搭 App（无生成式 AI 能力）；差异化 = 对话式入口 + 私有衣橱数据 + 效果图文案一体化
6. **团队介绍** — 占位（⚠️ 待用户补充成员信息）
7. **财务与融资规划** — 3 年收入预测骨架（电商联合佣金 + B 端客户数 x 客单价双模型，数字占位 ⚠️ 待校准）、融资需求与用途（占位 ⚠️）
8. **落地规划与就业带动**（区域赛事定制章节）— 落户金牛区 AI 数字创智元 OPC 社区意向、3 年团队扩张与用人计划、与园区「算力补贴」政策的衔接
9. **未来展望** — 技术演进三步走（当前生成式效果图+AI 审核 → 接入专用虚拟试衣 Try-On 模型实现真人上身 → 与 3D 方案商合作身材尺码引擎，坚持轻资产不自研 3D）、品类扩展（美妆/配饰/鞋包）、平台化（开放 API、穿搭生态）、与城市消费场景结合（即时零售、商圈数字化）
10. **风险与应对** — LLM 成本、数据合规、巨头入场三条

## 写作纪律

- 只引用已核实数据并标注来源（统计局/纺联/服协/第三方报告），不编数字
- 技术描述与代码事实一致（Agent 名称、测试体系、日志体系均真实存在）
- **现状与规划严格分层**：已有能力用现在时如实写（可查证）；商业化内容一律用"规划/将/分阶段"表述并配路线图，不做任何"已接入/已合作"的虚假宣称（公告明确作假取消资格）
